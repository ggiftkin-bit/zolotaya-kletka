# Очередь · 0.27.4 сдан

Сданы сундук-ход-смерть 0.27.4 (сундук не глотает, фишка не отскакивает, смерть уводит домой, шапка тепла только при warmth < 35). Иконки 0.27.3. Шалаш и ход 0.27.2. Ход и рынок 0.27.1. Поляна 0.27.0. Стада 0.26.0.

Парковка: выборы; живая оплата; стол админа; цепь нфт; касса государства; стакан мира; ноша / перегруз / двойной потолок; сход 6c–6d.
