# Очередь края · 0.9.x, не фундамент

Дата: 2026-09-07.
Для автора и билд-режима.
Не сборка. Порядок слоёв.

Фундамент сдан, не трогать как следующую обнову: пни, хозяин клетки, почта, бой через `fight`, сверка 800 мс, канон справочника 0.9.1 (`3dcdd62`).

Сырое сейчас — край. Собирать **только текущий** бриф. Соседний не «заодно».

## Закон каждого кодового среза

- `store.ts` ~188 КБ. Новое правило — модуль гнезда. Стор только клеит. Отдельной версии «распилить стор» нет.
- `src/lib/multiplayer/p2p.ts` — чужой контур. Стол идёт через книгу. Не чинить и не подключать «заодно».
- На экране свой двор — «you». В книге `owner` — `user_id`. После заливки свой id снова становится «you», иначе `isYours` соврёт свой двор чужим.
