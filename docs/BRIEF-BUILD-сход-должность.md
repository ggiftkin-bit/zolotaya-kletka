## Когда откроете — лестница, не комета

1. Имя и улица для двух почт. `village` на клетках в книге, не только «you».
2. Один староста: `user_id` на клетках деревни. Не ник в чате.
3. Казна деревни — отдельное золото, не сумка старосты.
4. Смена: сход, назначение, смещение.

Пока очередь 1–5 не сдана — этот бриф не открывать в билд-режиме.

Не делать даже потом в первом слое власти: поход, таран, стрельбу башни, чат схода, p2p.

Правило — `pact.ts` + книга. Не `store.ts`.
