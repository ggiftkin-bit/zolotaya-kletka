# Бриф · сытость, тепло, жажда

**Сдан 0.21.2.**

Пляшем от 0.21.1
Версия сдачи: 0.21.2

Сила и раны уже книга. Сытость, тепло и жажда ещё с кармана.

---

## Закон

1. Upsert не берёт с клиента: `satiety`, `warmth`, `water` (и по-прежнему не берёт gold / inventory / energy / hp / life / deaths / due / gifts).
2. Стол читает эти три только из книги.
3. Меняются делом. Часы — книги.

Роды:
- съел — еда ушла из сумки книги, сытость как сейчас
- голод тика мира — книга снимает сытость по старому правилу
- тепло: крыша греет, ночь стыдит — часы книги
- напился у реки / колодца — вода тела выросла; ведро `pail` если сейчас отдельно — тоже дело, не карман
- жажда тика — книга снимает `water` по старому правилу

Цифры не выдумывать.

---

## Не в этом срезе

Админка, логи, звёзды, кожа, выборы.

`store.ts` только клеит. v8, сид.

## Приёмка

1. Съел хлеб — сытость выросла, после заливки те же цифры.
2. Напился у реки — вода выросла, после заливки то же.
3. Подмена `satiety` / `warmth` / `water` в записи фишки счёт не меняет.
4. Без еды и без глотка цифры сами не растут.
5. Кружка и 12 сдач как в 0.21.1.
