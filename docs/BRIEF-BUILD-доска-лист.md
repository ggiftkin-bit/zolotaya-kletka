## Почему пусто

Столб без хозяина не давал «Повесить». Текст говорил «с листа», кнопки не было.

## Контракт

1. Ничей знак у тракта: стоя рядом можно повесить. Первый заказ ставит хозяина столба.
2. Пустой лист — не молчание: наклейка «Повесить заказ», «К калитке», «На склад».
3. Шапка-обучение продолжается после двора: вбей доску → повесь заказ. Стоишь на доске — шапка говорит про Повесить.
4. Букварь «Доска»: шаг за шагом. На клетку доски услугу не вешают.

## Приёмка

1. Встал на свой знак у тракта — есть «Повесить заказ».
2. Повесил привези на калитку — строка на доске, хозяин столба ты.
3. Шапка после тепла: про доску, не только «зайди в шалаш».
4. Калитка и тачка как были.

## Не делать

Выборы, кожу, живую оплату, стакан мира. v8 и сид не менять.
