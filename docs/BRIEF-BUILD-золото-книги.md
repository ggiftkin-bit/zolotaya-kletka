# Бриф · золото считает только книга

**Сдан 0.19.0.**

Пляшем от 0.18.2. Тачку, доску, контору, тын не ломать. Выборы и кожу не открывать.

---

## Закон

1. Запись фишки не берёт с клиента `gold`, `due`, `gifts`. Нет строки — старт 20.
2. Стол читает золото из книги. `due` складывается на чтении, как было.
3. Цифра меняется только делом книги. Клиент говорит род (`boost`), не новую сумму.
4. Контора, лавка тракта, услуга, ордер — как были, золото из книги, не второй раз на столе.

Цены как были: кружка 8, ускорить 12, руки 16, залог 20, пошлина смерти, тачка 20, лошадь 40, телега 48.

Донат +50 остаётся испытанием, только через книгу.

## Приёмка

1. Донат +50 — выросло. Закрыл стол, открыл — те же 50.
2. Купил значок — сгорело 200, после заливки число то же, «заказан».
3. Сдал пачку тракту — золото пришло из книги.
4. Вторая почта это золото не получила.
5. Подмена `body.gold` в записи фишки счёт не меняет. После входа — число книги.
