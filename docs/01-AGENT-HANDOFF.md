## Встреча и бой (слой 0.8.10)

### Правило

Бой **только на одной клетке**. Соседняя — `meetWhy`: «Встань на его клетку.» Река/ров без моста — нельзя. Лежит (`life === "down"`) — «Не добивать.»

Путь **не** открывает лист сам. `maybeMeetHere` **удалён** — не возвращать.

Ступил на живого или манекена:

1. путь стоп (`advanceTravel` / `skipTravel`);
2. клетка помечается `inspect: {x,y}` — пузырь;
3. две кнопки: **Встретиться** / **Пройти мимо**.

Без кнопки «Встретиться» два человека на клетке расходятся.

### Ignore

Модульная строка `meetIgnore = "x,y,id"` в `store.ts` (не в сейве).

- `meetPass` ставит ignore и закрывает лист.
- Пока стоишь на этой клетке — кнопки встречи скрыты (`meetIsIgnored` в `TileBubble`).
- Ушёл с клетки (`catchUpSim` сверяет x,y) — ignore сбрасывается. Вернулся — снова кнопки.
- Ночью против **манекена**, если уже в листе и ход твой: `leaveChance`. Провал — ход манекену, `dummyAnswer` через 400 мс.

### Шаг

Страж `if (!s.meet || s.meet.turn !== "you") return;` в `meetHit` **не снимать**. Пачка кликов = один удар за шаг.

Порядок удара:

1. `meetWhy`
2. −2 силы
3. `strikeDmg` как есть (оружие, профессия, голод, холод, ночь, двор, броня, 1…12)
4. **всегда** вычесть hp и показать число: флоатер `удар 6`, лог `Ударил Имя: −6`
5. `hp <= 0` → `life: "down"`, встреча закрыть, ноша на клетке, добивать нельзя
6. иначе ход цели. Манекен ~400 мс `dummyAnswer`. Живой — ждёт его кнопки, автоудара нет

«Пройти мимо» в листе **не** серое на чужом ходе (живой иначе застревает навечно: сети удара нет). Удар и сдача — серые, текст «Ждёт ответа».

«Кинуть ношу» / «Говорить» под «ещё». Сдаться / кинуть ношу по смыслу не менять.

### Живой на этом клиенте

Полный сетевой бой **не делать**.

- манекен: hp в `dummies`, пишет не-live ветка `applyDummy`
- живой в `others`: снимок на время встречи
  - поля `Meet`: `foeHp`, `foeHand`, `foeBody`, `foeShield`, `foeHelm`, `live`
  - `rememberLiveFoe` / `liveSnap` в `fight.ts`
  - `liveAsDummy` читает снимок, не вечные 100 **после первого удара**
  - `foeOf` в store накладывает `meet.foeHp` на павна
- ветки `if (live) { … return; }`, которая глотала урон, **нет**. Урон и смена хода общие.
- закон двора / яма — только манекен (`!live`)

Первая встреча с живым всё ещё 100 hp: с книги приходит только `{id,name,color,x,y}`. Второй аккаунт чужой урон может не увидеть — так и задумано в этом слое.

Когда откроете слой книги — тем же снимком уйдёт удар. Не изобретать отдельный «книжный кулак».

### Лист

`MeetSheet` в `Hud.tsx`: `maxHeight: min(42vh, 18rem)`, не 62vh. Крупно имена и две полоски ран, чья очередь, одна строка сила·рука, три кнопки.

### Функции

| что | где |
|---|---|
| путь стоп + inspect | `advanceTravel`, `skipTravel` |
| открыть лист | `startMeet` ← пузырь «Встретиться» |
| мимо | `meetPass` |
| удар | `meetHit` |
| ответ манекена | `dummyAnswer` |
| снимок живого | `rememberLiveFoe`, `liveAsDummy` |
| кто на клетке | `occupantAt` (сначала `others`, потом dummy) |

## Земля (вид)

Флаги в `constants.ts`: `FILL_TEX`, `PAINTED_PROPS`. `false` — плоские `BIOME_FILL` и эллипсы, **код не удалять**.

Пол: `useFill` + `createPattern` в мировых координатах. Сменил масштаб заливки — бампни `FILL_CACHE` (сейчас `"v7"`), иначе браузер держит старый паттерн.

| что | как |
|---|---|
| равнина / commons | луг `v3-ravnina`, `FILL_SCALE.meadow = 0.18` |
| брусчатка | только `plot` без грядки и каменный тракт, `cobble = 0.08` |
| пашня | биом `fertile` **или** `building === "field"`: `v2-pashnya.jpg`, `field = 0.14`. Двор (`plot` без грядки) пашней не затирать. `paintFieldEarth` рисует борозды у построенной грядки |
| лес | мох `v2-les-pol`. Ели спрайтами вторым проходом север→юг, `collectPaintedProps`, общий y-sort. В колее тракта крон нет. Размер крон ~1.15–1.55 TILE |
| река | `paintRiverGround`. Форму не «улучшать». Брод мельче + камни. Мост поверх |
| тын | линия `paintFence`, не спрайт `v2-tyn-vertikal.png` |
| тракт | узкая лента `BAND = round(TILE * 0.32)`, `v3-trakt` только в полосе |
| суша | мягкое округление `LAND_OUTER = 7` / `LAND_INNER = 4` в `paintSoftFloor` |

`floorOf`: field ← `building==="field"` или `biome==="fertile"`; moss ← лес; swamp; иначе meadow. Вода / яма / брусчатка двора — `null`.

Траву на диком fertile не путать с грядкой. Сбор «Нарвать траву» с камыша/пучка — `places.ts` / пузырь. `stampMeadowHerb` не ставит траву на `building==="field"`.

## Хозяйство (не ломать цифры без брифа)

- Сырьё в лавку **пачкой** (`SELL_GOLD` / пачки в `economy.ts`). Одно дерево ≠ 1 золото. `Math.max(1,…)` на сырьё нельзя.
- Вес полного ведра растёт с `pail`. Напиться у воды = тело 100. Глоток из ведра на любой клетке, +25, не тик мира.
- Сытость: крыша −1, поле −2 / тик. Сила за клетку: пешком −0.5, конь −0.2, тачка −0.7, телега −0.4. Потолок силы 18.
- «Голоден» только если сытость **< 25**.
- Тик 30 с. День и ночь по 4 тика = по 2 мин.
- Старт: 20 золота, топор в руке, еда ×6. Кружка 6. Ускорить ход 8. Залог / наём 12.
- Туман: живое пятно пишется в `FOG_MEM` сейва. Книга мира — пятно + отпечаток, не все 9216 клеток за раз.
