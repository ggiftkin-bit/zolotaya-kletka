# Бриф · тачка и лошадь на клетке

Пляшем от 0.16.0
Версия сдачи: 0.17.0

Телега уже `tile.wagon`. Тачка и лошадь сейчас — число на фишке.

---

## Стоянка

1. Не вещь сумки. `ItemId` не заводить.
2. На клетке: `tile.cart` / `tile.horse` = id хозяина. Идёшь — `transport` cart/horse, клетка пустая. Оставил — снова на этой клетке.
3. Оставить — любая проходимая, не река.
4. Упал / убит / яма — сразу на этой клетке. Фишка без них.
5. Старый сейв: `carts`/`horses` > 0 — один раз рядом с фишкой и обнулить счёт.

---

## Увод

Чужая стоящая тачка/лошадь/телега — дело, не мгновенный тык. Тот же ряд, что куча и засов: `crime.ts` + книга.

- Без закона на клетке — увёл, стал твой `transport` или стоит уже как твоя на клетке. Хозяин открыл — его уже нет.
- Двор с законом — дело «увести». Срыв — след, как кража кучи. Доделал — увёл.
- В сумку не кладётся. Хозяин может быть оффлайн. Манекен не нужен.
- Свою забрать — не дело и не след.
