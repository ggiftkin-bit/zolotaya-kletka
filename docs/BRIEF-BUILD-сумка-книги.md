# Бриф · сумка книги

Пляшем от 0.19.0
Версия сдачи: 0.20.0

Золото уже книга. Сумка ещё приходит с телом фишки — нарисовал дерево, сдал тракту, получил живое золото.

---

## Закон

1. Upsert фишки **не берёт** с клиента `inventory` (и не берёт `gold` / `due` / `gifts`, как в 0.19.0).
2. Стол читает сумку только из книги.
3. Ноша меняется **делом книги**. Клиент говорит род и клетку, не новый мешок.

Роды (книга сама смотрит кучу / лес / сундук / склад / рецепт):
- срубил / снял / выкопал — сколько даёт клетка, не стол
- поднял кучу / положил кучу / сундук / склад `pullNeed`
- крафт у станка — сырьё сняло, готовое добавило, рецепт `craft.ts`
- сдал / купил у тракта — уже есть с золотом, дописать ношу
- кража кучи / сундука — как сейчас вещь едет в сумку вора в книге
- услуга отвези / привези / сделай — эскро и выдача уже в книге, не писать сумку сверху

Ноша и вес тачки проверяет книга по `CAPACITY` и текущему `transport` из книги, не стол.

Силу, hp, потолок сдач тракту, ловлю почт, звёзды. Золото 0.19.0 не пересобирать — только подключить ношу к тем же делам.

`store.ts` не читает мешок. v8, сид не менять.

1. Срубил — дерево в сумке из книги. Закрыл стол, открыл — то же число.
2. Сдал пачку тракту — дерева меньше, золото больше, оба с книги.
3. Подмена `body.inventory` в записи фишки мешок не меняет. После входа снова сумка книги.
4. Без станка / без сырья кирпич не появляется.
5. Золото 0.19.0 живо: донат +50, значок, подмена gold не работает.
