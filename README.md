# Золотая Клетка

Настольная песочница жизни и промысла на клетчатой карте. Соло-альфа и общая поляна: ходишь, строишь, торгуешь, крадёшь, сажаешь, ездишь на лошади и телеге, встречаешься на клетке.

Вход — почта и пароль. С другого устройства — та же фишка. Земля общая в книге мира. Карман браузера (`zolotaya-kletka-v8`) — черновик.

Смерть — нокаут, не вайп: вещи кучей на клетке, золото штрафом.
