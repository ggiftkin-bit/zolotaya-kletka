# Золотая Клетка

Настольная песочница жизни и промысла на клетчатой карте. Сейчас соло-альфа: ходишь, строишь, торгуешь, крадёшь, сажаешь, ездишь на лошади и телеге, вешаешь замки на сундук и калитку.

Сохранение в браузере. Смерть — нокаут, не вайп: вещи остаются кучей на клетке, золото снимается штрафом.

## Стек

- React 19 + TanStack Start
- Zustand
- Canvas 2D

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:8080`.

```bash
npm run typecheck
npm run build
```

## Что уже в игре

- Карта, деревни, лавки, кузница, плотницкая
- Сумка 4×4, сундук, двор, забор и калитка
- Ремесло, еда, сила, сон в шалаше
- Лошадь, тачка, телега
- Замок на сундук и засов на калитки двора
- Тюрьма, кража, ночной налёт

## Лицензия

Исходники пока без отдельной лицензии — репозиторий для хранения и совместной работы.
